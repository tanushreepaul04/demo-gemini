# My agent: Travel Concierge Agent

One-liner: A conversational agent that helps travelers discover, plan, and customize trip itineraries with a catalog of destinations and interactive activity cards.

Tool coverage:
- Memory: User travel preferences (budget tier, travel style, dietary restrictions, preferred climates, past visited destinations)
- Tools: Destination lookup, weather forecast check, itinerary builder
- Catalog/UI: Recommended destination cards, venue details, and structured day-by-day itinerary tables
- Image gen: Generates scenic visuals and landmark previews of recommended travel destinations
- Sandbox: Travel budget and currency conversion calculations

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): Live Maps API lookup, code sandbox for budget & split-cost calculations, Cloud Trace observability
